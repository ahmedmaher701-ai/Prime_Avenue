# Prime Avenue | برايم أفينيو

Mobile-first Arabic/English community website for Prime Avenue, Hadayek October, Giza.

## Preview

Open `index.html` or publish this repository through GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Current status

This is an **early front-end prototype**. Registration, issues, ideas and discussions currently use browser localStorage only; they are **not shared between residents**. Photo uploads, secure phone authentication, resident approval, admin management, notifications, moderation, verified nearby listings and database-backed functionality are not implemented yet. Do not use for real resident records until authentication, authorization and secure storage are configured.

## Next phase

Connect Supabase or another backend with secure sign-in, row-level security, admin moderation, photo storage and shared data. Add the official compound logo asset and verify local business directory contacts before publishing listings.
